### About Me

I am an engineering student interested in how mathematical models translate into physical hardware and reliable software. My work spans control theory, electromechanical simulation, and practical low-level tooling.

- 🎛️ **Control Theory & Modeling**: Modeling electromechanical systems, state-space formulations, transfer functions, and PID controller synthesis with anti-windup clamping.
- 🛠️ **Systems & OS Tooling**: Reverse engineering installer payloads, binary stream extraction, and Windows driver deployment automation.

- 🔬 **Simulation**: Root locus, Bode frequency-domain stability analysis, and dynamic plant simulations using MATLAB, Simulink, and scientific Python libraries.

### Featured Projects

#### ⚔️ [DeArmour](https://github.com/mustafakorkunc/asus-dearmour)
> *Open-source Windows driver extraction and deployment utility for ASUS laptops.*
- Scans and carves bare-metal INF/SYS/CAT driver payloads out of bloated OEM installer wrappers (`SetupLdr`, `AsusSetup`, Inno Setup).
- Direct integration with official ASUS Support REST API endpoints and BIOS registry hardware detection.
- Generates 1-click administrative `pnputil` batch installers with zero background services or telemetry daemons.
- Built with Python, featuring both a Catppuccin-themed GUI and a scriptable CLI.

#### 🔬 [DC Motor PID Control](https://github.com/mustafakorkunc/dc-motor-pid-control)
> *Closed-loop speed and position control simulation suite for DC servomotors.*
- First-principles electromechanical equations modeled via Kirchhoff's Voltage Law & Newton's Second Law.
- Continuous and discrete PID controller implementation with anti-windup clamping and actuator saturation bounds.
- Automated transient response analysis (Rise Time, Settling Time, Overshoot) and frequency-domain stability verification (Gain & Phase margins).
